If you know the phrase, type it here. It costs nothing.

2. The seal and the phrase

How this works

Each seal keeps a random salt and a fingerprint of the phrase (PBKDF2-SHA256, usually 600,000 rounds). This page computes the fingerprint of what you type with the same salt and compares the two. Letter case and extra spaces do not matter. The page also recomputes both hash chains, so you can see whether the copy has been altered.

A match found here is not recorded anywhere. If the website still exists, enter the phrase on the seal's page as well, so the opening is logged publicly with its date.
